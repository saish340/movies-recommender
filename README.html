Movie Recommender App

A modern Flask-based movie recommendation application with a sleek UI that allows users to search for movies, view details, read reviews with sentiment analysis, and discover similar films.

Features

  • Beautiful responsive design for all device sizes
  • Movie search with dynamic suggestions
  • Detailed movie information including cast, ratings, and plot
  • Review sentiment analysis using TextBlob
  • Similar movie recommendations based on genre
  • Categorized movie sections: Popular, Now Playing, Top Rated, and Upcoming
  • Modern UI with animations, hover effects, and gradients

Setup Instructions

1. Install Required Packages

pip install flask requests beautifulsoup4 textblob

2. OMDb API Key

This application uses the OMDb API to fetch movie data. Your API key is already set in the code: 8aad5b1b

3. Run the Application

python main.py

The app will be available at http://127.0.0.1:5000

Note: For production use, consider getting your own OMDb API key and setting it as an environment variable instead of hardcoding it.

Customization

You can customize the application in several ways:

  • Change the color scheme by editing CSS variables in style.css
  • Modify the movie categories in main.py
  • Add additional data points from the OMDb API
  • Extend the sentiment analysis functionality

Sentiment Analysis

The app uses TextBlob to analyze reviews and categorize them as positive, negative, or neutral based on the sentiment polarity score:

  • Positive: score > 0.2
  • Negative: score < -0.2
  • Neutral: -0.2 ≤ score ≤ 0.2
